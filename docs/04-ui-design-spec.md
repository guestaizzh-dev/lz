# 老子道学书院：App界面设计规范

状态：旧版方案已被用户否定，不再作为App实施基线。App等待用户提供设计；后台已按最新指令改为Ant Design Pro官方模板二次开发，见apps/admin/THIRD_PARTY.md。下文保留历史方案，不能据此继续实施。

## 设计方向

当代书院：内容像一本安静、清晰的读物，功能像易用的现代学习App。原始策划明确要求米白、黛青、水墨；本项目沿用这些品牌颜色，用留白和排版体现书院气质。

首页不堆叠七个相同功能宫格。用一幅大面积但克制的横向山水作为主视觉，安排每日经典、继续研习、内容荐读和近期活动。课程以学习目标、课程形态和老师信息组织；商城以实物摄影/干净插画、规格和交付信息组织。书法仅用于品牌标题/章节装饰，正文不用难辨识字形。

## 视觉令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| paper | #F6F5F0 | 页面底色，低饱和米白 |
| surface | #FFFFFF | 表单、商品、内容容器 |
| ink | #202F2A | 正文、标题 |
| secondary | #65746D | 次级说明，仍保证阅读对比 |
| forest | #285C48 | 主按钮、选中项、品牌黛青 |
| mist | #E5ECE5 | 轻背景、内容分类 |
| line | #DEE3DB | 分隔线 |
| vermilion | #A64D37 | 少量印章、价格/重要标记，不作为全局第二套主按钮 |
| danger | #AC3B36 | 失败和破坏性操作 |

间距以4为基数：4/8/12/16/20/24/32/40。375—430px基准宽度；左右20px内容边距。容器圆角12—18px；大面积阴影只用于浮层，不给所有列表加阴影。

正文16px/约1.65行距，列表标题17—18px，页面标题26—30px，辅助文字不小于12px，关键操作不小于14px。品牌和阅读标题用可授权的中文宋体/衬线；其他内容采用平台清晰无衬线。长文支持字号调整；核心触控区至少44px。

## 页面构图

- 首页：品牌/消息 → 欢迎和搜索 → 山水专题 → 每日经典 → 继续学习 → 荐读与直播/活动。游客展示探索内容，不伪造其学习历史。
- 学堂：标题/学习入口 → 分类筛选 → 一门主推课程 → 分类课程列表；列表明确课程时长、章节数、价格/权益。
- 发现：文章/名师/直播/社区/活动顶部分区；初始为文章，卡片重视标题和短摘要。
- 好物：分类 → 主推实体好物 → 商品双列；购物车入口有真实数量，价格、售罄、规格和交付清楚。
- 我的：游客登录引导或真实用户摘要 → 学习/订单/收藏概览 → 会员 → 学习档案与服务 → 设置/隐私。
- 详情：清晰返回、题图或媒体、作者与标签、正文/章节；主要动作固定在安全区上方，不能遮住最后一段内容。
- 交易：结构化商品信息、优惠、生效/交付说明、真实金额、付款方式；禁止把模拟支付成功做成生产体验。
- 后台：Element Plus为基础；深黛青窄侧栏、浅色内容面板、明确表格/表单。发布与资金操作有状态和审计入口。

## 交互状态

每项功能必须具备加载、空、失败、无权限或登录引导等适用状态。按钮点击后给出明确反馈，避免双击产生重复交易。页面切换和轻反馈控制在160—240ms；尊重减少动画设置，不做持续装饰动画。

底部导航：首页、学堂、发现、好物、我的，图标同一线条家族。顶部系统安全区留足空间；底部操作栏和键盘互不遮挡。

## 素材与真实性

山水为项目原创矢量插画，可在App和设计预览复用。公开经典可使用原文，但解释文字标记为书院编辑内容。开发目录中的示例老师/课程/商品明确属于演示数据；生产发布需要真实审核资料和版权，不把虚构老师或会员数作为已存在事实。

## 视觉验收

375/390/430px下检查五个主页面和关键详情/订单页面；无横向溢出、文字截断或遮挡。字体放大后关键操作仍可达；表单错误能读懂；图标按钮有名称。截图留存到outputs/ui，设计预览通过不等于Android/iOS原生UI验收通过。
