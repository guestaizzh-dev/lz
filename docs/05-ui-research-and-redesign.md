# 界面调研与重设计决策

日期：2026-10-06。状态：历史调研与设计记录。用户再次否定此轮App设计，决定自行设计；App设计板未获采用，停止据此实施。最新后台指令为直接使用Ant Design Pro官方模板二次开发。

## 主题与旧版问题

原文定位是老子道学思想、文化传承、名师研习与实践。用户涵盖18—70岁。米白、黛青、水墨与古籍是视觉材料，阅读和购买路径仍必须清晰。

旧版首页“让心，慢下来”没有明确表达道学；连续的绿色大卡片、相同圆角、低细节山水SVG和泛泛的诗意副标题形成模板感。文章、课程、商品复用同一插画，不能区分内容类型。标题没有体现章次、经典版本与内容来源；后台的装饰文案占用运营空间。调整需要同时改变内容层级、封面材料、字体、版式与界面组件。

## 设计落点

方向：**当代古籍阅读与书院研习**。暖米白纸色、石墨文字、少量黛青和朱砂。整体依靠中文宋体标题、清晰的正文、原典章次、真实水墨与细线分隔建立气质。大面积渐变、装饰阴影、统一的绿色卡片和重复营销口号取消。

首页先展示书院身份、研习主题，再给一段带出处的经典与实际课程；学堂用封面与课程资料组织，而不是商品式通栏巨卡；发现是可查询的内容目录；好物采用书籍与文创陈列；我的重在个人记录与服务，不伪造会员状态。

当前没有真实商品摄影，开发商品使用本项目原创的书籍封面与封面样机，明确为示例。不给不同商品套用无关古画，也不用馆藏茶碗冒充商品实拍。真实商品上线需要其实际摄影和规格。

## 后台具体采用方案

直接拉取官方Ant Design Pro v6.0.3完整模板，将src/config/public及许可导入apps/admin，然后在模板内二次开发。保留原版ProLayout外壳、dashboard/analysis图表组件及样式、LoginForm、HeaderDropdown、SettingDrawer、异常页面和通用组件。

使用上游配套React19.2.7、Ant Design6.6.0、ProComponents3.1.14-2与Umi4.7.22；登录/会话/退出替换为已有HttpOnly Cookie与CSRF服务，文章工作流放入模板table-list模块。清理无关聊天机器人、注册、演示表单/列表/账户等页面以及旧手写概览。分析图表保留示例数据并显式标注，不能作为真实经营统计。来源与完整验证记录见apps/admin/THIRD_PARTY.md及03-development-progress.md。
