## 同步修复

- Windows Documents跨盘重定向时，开发PostgreSQL启动脚本正确定位原生工具。
- 限流键沿用既有主键，消除空字符串唯一字段导致登录500的问题。
- 课程发布只复制章节业务字段，保留说明、老师、退款及完成规则快照；不把新增内部字段传进Lesson创建。
- 会员套餐内容修改自动生成新版本，历史版本不被改写；会员有效区间和老师预约时段由数据库排斥约束限制重叠。
- 七种内容实体同步统一Resource；旧文章收藏与Reaction双向同步。
- SKU自动形成销售项，购物车引用该销售项；自动销售项通过SKU维护，避免价格或引用关系被独立改坏。
- 媒体写入真实上传者、SHA256、文件就绪状态及私有可见性；开发导入使用无登录能力的冻结主体。
- 后台缓存因C/D盘路径映射加载两份React时关闭MFSU；生产build和dev不能同时改写Umi生成目录，构建后重启开发服务。
- 通用SQL接口把无时区的旧Prisma时间按UTC解读，业务日期以原始YYYY-MM-DD返回，避免Windows时区造成日期偏移。
- 动态新建表单按数据库布尔默认值初始化开关；ProTable使用当前版本的search配置，删除无效搜索字段；Alert沿用Ant Design 6的title属性。

## 尚未完成的业务闭环

本轮完成的是数据库与数据维护基础，不能把建表或后台CRUD当作原始策划所有功能完成。

1. 新TradeOrder、核验支付、退款、发货、数字交付、积分/礼物/财务账本和结算，尚需相应业务流程、渠道回调、幂等及资金核对；当前没有真实支付配置，不允许后台制造成功交易。
2. ArticleRelease/Block正式版本发布、数字资料版本发布、PlanBenefit权益发布、FeatureConfig版本发布及合作合同审批，还需专用审核与版本操作；通用工作台只能查询这些版本事实。
3. 作业、帖子、预约、直播、活动、营销、客服等表和后台维护能力已具备；App对应流程、课程准入、老师学员归属、自动通知、第三方审核/推送/音视频接入仍需继续实现。
4. 现有地址专用接口仍保留旧的明文兼容字段；新增Cipher输入已加密并隐藏，但不能宣称全项目所有历史个人信息都已改为加密存储。生产隐私治理需统一专用接口与加密字段。
5. 本轮未重新打包App或验收iOS，也未部署生产。旧开发预占订单继续明确标为未付款，不等同于新交易闭环。

这80个受控实体的查询和写入限制是已完成的数据管理规则；其中尚未实现的所属流程仍计为未完成。此前原始需求完成度不能仅因新增CRUD页面而改成“全部已完成”。

## 使用与后续开发

- 后台开发入口：[http://127.0.0.1:5173/data](http://127.0.0.1:5173/data)。API运行于本机3000，PostgreSQL运行于55432。
- 本地管理凭据保存在被Git忽略的 `.runtime/admin-bootstrap.json`，未写入报告、源码或测试证据。
- 普通实体写入需要操作原因；修改/删除带详情中的 `_revision`。记录仍被引用时返回409，先处理关联记录或停用该配置。

- 本轮工作留在当前工作区供查看；没有推送远程、合并分支或部署生产。
