## 1. 本阶段目标

接续数据库与通用 CRUD 阶段，把原始策划的课程研习、作业提交、老师指导落实为可操作的业务流程。App继续使用用户设计图的米白/墨青、宋体阅读与细线列表；后台在官方 Ant Design Pro 模板中新增「教学与作业」，不另造后台框架。

闭环：管理员分配课程教学人员或手动授权学员 → 老师保存草稿、发布作业 → 学员提交正文及图片 → 老师完成点评或退回补充 → 学员查看站内消息与点评 → 退回后按新修订再次提交。

本轮不重建数据库，不清空已有开发数据，不引入新数据库迁移。复用 CourseStaff、Assignment、Submission、TeacherReview、AttachmentBinding、Enrollment、MediaAsset、Notification、IdempotencyRecord 和 AuditLog。

## 3. 本轮接口

以下均以 `/api/v1` 为前缀；沿用现有后台会话/CSRF与App令牌鉴权。

| 接口 | 用途 |
| --- | --- |
| GET `/admin/teaching/courses` | 当前教学账号可管理课程 |
| GET/POST `/admin/teaching/courses/:id/staff` | 教学人员列表/分配，仅管理员 |
| POST `/admin/teaching/courses/:id/staff/:staffId/revoke` | 按版本撤销教学归属 |
| GET/POST `/admin/teaching/courses/:id/assignments` | 作业列表/创建草稿 |
| PATCH `/admin/teaching/courses/:id/assignments/:assignmentId` | 按版本编辑草稿 |
| POST `/admin/teaching/assignments/:id/transition` | 发布/关闭 |
| GET `/admin/teaching/assignments/:id/submissions` | 分页查看全部修订 |
| GET `/admin/teaching/submissions/:id` | 教学人员查看提交及点评 |
| POST `/admin/teaching/submissions/:id/review` | 完成点评/退回补充 |
| POST `/admin/courses/:id/grant` | 复用现有手动授权接口 |
| GET `/learning/courses/:id/assignments` | 学员作业及完成统计 |
| POST `/learning/assignments/:id/submissions` | 提交文字和已上传附件 |
| GET `/learning/submissions/:id` | 学员查看自己的提交与点评 |
| POST `/learning/submission-images` | 私有图片上传 |
| POST `/learning/submissions/:id/images/:assetId` | 学员附件票据 |
| POST `/admin/teaching/submissions/:id/images/:assetId` | 教学人员附件票据 |
| GET `/media/stream?ticket=…` | 复用现有受控媒体流 |
| GET `/me/messages` | 私人消息分页与未读数 |
| POST `/me/messages/:id/read` | 标记自己的消息已读 |
