# 会员五档调整

后台按五个档位整理，以及对现有未售套餐的安全对齐和后续发布，见 [106](106-course-study-and-membership.md)。

注册账号即为基础会员；铜牌、银牌、金牌、钻石四档使用现有会员套餐与权益版本机制。为保留旧订单和授权，付费套餐沿用内部层级 1—3，分别对应铜、银、金；钻石为内部层级 4。基础会员不创建付费授权，不自动获得付费内容、折扣或配额；管理员面向全体会员的直播允许已注册用户观看。其他按内容权益等级限制的直播和课程仍按实际权益鉴权。

本次扩展数据库约束和后台、App 档位展示，恢复运行必需的权益定义；不凭空设置各档售价、期限或附加权益。运营需自行创建套餐并配置真实价格和权益，真实支付仍受原有渠道门槛约束。已有订单和权益版本不重写。

验证：API 构建、后台构建与 App Web 编译；会员套餐、权益和直播专项 24 项通过。后台及 API 发布后，Android 0.3.21/code26 预览包已包含五档会员和首页展示功能，并已同步固定下载入口，详见 [105](105-home-hero-configuration.md)。原计划 0.3.20 已取消。Android/iOS 真机与真实支付未验收。
