# 首页主图、轮播与视频

运营在后台「系统配置 → 首页主图与视频」选择原有画面、图片或视频。图片从本地上传或素材库选择：一张直接展示，多张按顺序轮播，可调整顺序；视频使用 MP4 分片上传并经服务端转码，处理完成后保存。清空配置后恢复原“上善若水”画面。App 回到首页时重新获取最新配置；视频默认静音循环，可使用播放控件。

首页视频使用独立上传用途，仅当前配置引用的已处理视频可公开读取，支持 Range；切换后旧视频地址不可再访问。公开图片与课程、数字资料及私人媒体分离。配置保存沿用版本校验和操作审计，不创建测试内容或改变既有业务数据。

验证：隔离库接口测试覆盖默认画面、单图、轮播顺序、错误素材、并发冲突、视频分片/转码、Range 和撤回；后台与 App Web 构建成功，隔离浏览器实测上传单图、双图轮播和视频，页面无 JavaScript 错误。原生设备播放和 iOS 未进行验收。
