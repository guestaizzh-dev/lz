# 课程学习与会员档位整理

## 本轮范围

- App 移除“课程版本与交付处理”页面及入口，学习页以播放器、章节切换和课程目录为主；停止交付时保留联系客服和订单售后途径。原有订单、授权、课程版本与学习记录不删除，旧通知改为打开课程详情。
- 商品详情及购物车数量使用明确的减号、数量和加号，数量仍受库存及原有上限约束。
- App 与后台统一五档：注册会员、铜牌、银牌、金牌、钻石。注册即为注册会员；付费档位由后台分别配置套餐，不预设价格或自动启用支付。
- 线上发现三条未启用且无订单、授权及额外权益引用的旧套餐；仅在安全条件仍全部成立时，把“会员 / 铜卡会员 / 银卡会员”对齐至注册 / 铜牌 / 银牌，保留原 ID、价格、期限和历史权益版本，并记录审计。金牌、钻石不虚构价格。

## 本地验证

- API 和后台构建、App Web 与 Android 蒸汽资源编译通过。
- 会员、课程、通知和学习相关专项 35 项通过；独立数据库的套餐整理及状态改变时事务拒绝验证通过。
- 浏览器使用模拟接口核对视频学习页、章节切换、商品数量上下限及 320px 下五档展示，共 4 组，无页面脚本异常；不代表真机或实际媒体链路验收。

## 发布状态

后台、API 与 0.3.22 Android 包按发布记录另行更新。正式支付、iOS 和原生真机验收状态不因本轮界面调整而改变。
