## 会员管理

后台 `/memberships` 顶部新增「会员名单」，不再用历史授权记录冒充会员人数。全部注册用户、正常与停用人数、五档人数独立显示；可按档位、状态、昵称或完整手机号筛选、分页及刷新，结果手机号脱敏。点击「查看权益」复用已有权益与用量面板。后台操作指南同步增加名单使用方法。

统计范围为包含USER角色、未注销的正常/停用账号。每人按当前时间最高有效档位计一次；过期、未来生效、撤销和退款暂停的授权不参与，符合现有学习准入的退款暂停规则。没有当前付费授权即注册会员；停用状态单独显示，不表示能够登录观看。纯后台账号和注销账号不计入。汇总为全局人数，表格为当前筛选结果，避免搜索时误改总人数。

接口 `GET /admin/memberships/users` 仅管理员访问，受既有会员读取策略保护；分页、档位、状态和关键词校验，绑定SQL参数并转义模糊查询通配符，完整手机号支持现有加密检索。三个查询在同一可重复读事务取快照，不返回手机号密文或哈希。无数据库结构变更，不改原授权、价格、期限、权益、支付开关或用户数据。

App「我的」显示本人实际档位，会员中心始终显示「注册会员、铜牌会员、银牌会员、金牌会员、钻石会员」。档位展示与可售套餐分离，四档套餐尚未启用时仍可查看五档，明确提示未开放，不编造价格与权益。保留登录态隔离、失败提示和重试。

## 首页主图入口

后台 `/system/config` →「首页主图与视频」：选择「图片 / 轮播」后本地上传或从素材库选图，一张直接展示，多张按顺序轮播；选择「视频」上传MP4并等待处理完成，点击「保存首页展示」。选择「原有画面」可恢复原上善若水画面。App回到首页重新取配置，无需重新打包。沿105既有实现，本次核对入口，不替换线上素材。
