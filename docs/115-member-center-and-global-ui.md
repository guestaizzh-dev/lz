# 长期会员 代金券与全局界面整改

日期：2026-11-02。用户要求会员业务与全局UI一起实现；本地开发和验证，不访问服务器、不发布。

## 已确认规则

- 注册免费；铜/银/金/钻开通费分别365/998/1680/2980元，只购买长期资格，不形成现金余额。
- 生活馆按9.5/9/8.5/8折，图书按9.9/9.8/9.7/9.6折，图书不折上折。图书使用后台明确的价格品类，不凭商品名称猜测。
- 开通赠50/100/200/300份视频代金券，每份抵扣3元，长期有效；升级只补价格和累计赠券额度差额，已用券不补回。
- 会员开通及升级付款7天内未使用或占用该次权益可申请退款；升级退款恢复原等级。独立购券仅按未使用/未占用份数原路退回。
- 代金券仅用于正式付费视频，可与现金混用，也可全额兑换视频；不找零、不兑现。
- 会员首页完整对比五档并直达购买；会员栏目查看/购买代金券和来源记录，后台调整各档赠券数量及折扣，新配置不改写旧订单。

参考成熟电商的信息层级、卡片与购买流程；后台延续官方Ant Design Pro，组件遵循[Ant Design设计价值](https://ant.design/docs/spec/values/)中的任务导向和确定性，表单参考[Element Plus表单](https://element-plus.org/en-US/component/form.html)的字段分组及校验组织。参考设计理念，不复制品牌配色或引入多个组件库。
