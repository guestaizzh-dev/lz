# 120 · 商城分类、上架、优惠券与代金券链路整改

状态：本地实现、review、交易回归及构建通过，API、后台、Android新包及弹窗返修均已发布。用户最新授权更换背景、小幅优化、完成全部所述业务并在review后上线。

## 已确认缺口

1. App商城三入口写死，分类管理显示另一套旧商品分类；商品编辑另设折扣分类，配置与展示不一致。
2. 视频代金券管理复用会员权益页；售价与抵扣价值固定300分，客户端多处自行乘300。无法独立运营。
3. 代金券没有批次面额字段，若直接改全局常量会追溯改写老券价值，需新增批次条款并让报价/预占/消费/退款按批次核算。
4. 优惠券营销发放与视频代金券实体分开，但后台/客户端未清楚呈现边界；检查自动择优、叠加、不可用与退款恢复链路。
5. App课程页存在“获得课程权限后，长期访问所交付版本”等无用说明，按用户要求直接删除。

## 实施范围

- 分类管理统一维护生活馆/课件视频/图书入口名称、顺序、启停。Product.mallCategory 与交付类型、实物会员折扣规则独立；改名不改历史价格。
- 商城课件与教学课程独立；线上课件在商品资料面板独立上传、定价、发布、购买和播放，不创建或强绑Course。实物课件有自己的规格、库存、配送和售后，不因分类名含视频自动抵券。
- 分类到新建/上传/规格/售价/发布/App展示/支付权益完整核对。保留已有数字资料/服务等独立入口及历史订单，不能因三大入口让已有内容无法找到。
- 代金券独立售价、面额、启停与批次/订单管理；会员等级只管理赠券份数。已发券/订单条款冻结，新设置只影响后续发放。
- 优惠券维持营销减免，一单一张择优；代金券为视频专用抵扣权益，按批次价值、实付原价退款，订单取消/失败/退款返原券，防重复返还。
- 删除App页面重复介绍和内部术语。
