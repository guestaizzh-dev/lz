本轮操作前保留了仅本机、Git忽略的恢复快照，目录为 `.runtime/test-data-cleanup`；快照含旧账号验证信息和私人数据，不能提交、发布或作为截图分享。对外记录只保留清理统计。

## 从哪里开始

| 要做的事情 | 后台入口 | 操作顺序 |
| --- | --- | --- |
| 设置书院名称和客服信息 | 系统管理 → 系统配置 | 修改表单 → 填写原因 → 保存；首页数量、发帖开关也在这里 |
| 给同事开账号 | 系统管理 → 账号与会话 | 新建账号 → 分配角色；运营负责编辑，审核负责发布，老师只处理所属教学 |
| 发布文章 | 内容管理 → 文章与经典 | 新建草稿 → 填标题/来源/正文 → 保存 → 提交审核 → 审核发布 |
| 准备课程 | 内容管理 → 课程与名师 | 先录入并审核名师，再创建课程，添加图文、音频或视频章节 → 保存 → 提交审核 → 发布 |
| 上传课程音视频 | 课程媒体库 | 上传符合格式的文件，再在课程章节里选用；图文章节直接填写正文 |
| 给学员安排学习 | 课程与名师、教学与作业 | 学员先通过App注册；按实际需求授予课程访问权、分配老师，再创建和发布作业 |
| 管理活动 | 活动管理 | 新建活动 → 设置时间/地点/容量 → 提交审核 → 发布；付费报名和核销尚未接入 |
| 维护商品 | 商品与库存、配送计费 | 补齐商品/规格/库存/配送后审核；正式收款、物流及售后仍未接入，不能承诺已可销售 |
| 看反馈和内容审核 | 客服与反馈、社区与内容治理、评论审核 | 处理对应待办；工作台的「前往处理」会打开具体业务页面 |
| 查看谁操作过什么 | 系统管理 → 操作审计 | 按中文行为、模块、操作人和时间筛选；详情查看前后变更和请求编号 |

空列表和零指标表示尚未录入内容，不是程序故障。页面保留业务表单和真实流程，不自动用随机测试数据填充。

「高级数据维护」是技术排查/基础字典工具，原来的「业务数据管理」已改名并添加用途说明。日常运营不需要逐张表录入，不需要理解英文表名、UUID或流程事实表。账号操作中的「撤销会话」改为「强制退出」，「冻结」改为「停用」，审计主要行为和模块改用中文显示。

## 防止测试再次污染后台

标准命令 `services/api` 下的 `pnpm test` 先编译API，再创建唯一命名的本机临时数据库，应用全部手写迁移，在该独立库串行执行测试。测试媒体也使用独立临时目录；正常结束或测试失败时删除临时库和媒体目录。拒绝生产环境与非本机数据库服务器，不会重置日常后台数据库。

测试执行中的后台数据不再受角色策略、配置和临时账号影响。请使用标准命令，不要直接拿日常开发库运行单个HTTP/数据库测试。异常断电或强制杀进程可能留下独立的 `academy_test_` 临时库，但不会把测试记录写入后台正在使用的库。

验证：独立测试库**156项回归全部通过**，结束后临时库数量为0；后台类型检查与生产构建通过；API健康、管理员登录、40项权限、账号列表仅一个管理员和空目录已检查。真实后台浏览器登录、零指标及操作指引、账号列表总计1条通过，截图在 `outputs/admin-cleanup`。后台运行在 `http://127.0.0.1:5173`，API在3000端口，数据库在55432端口。日志 `.runtime/test-isolation-regression.log`、`.runtime/test-data-cleanup-admin-build.log`，清理统计 `.runtime/test-data-cleanup/report.json`。
