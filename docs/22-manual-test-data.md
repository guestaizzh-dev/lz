## 尚不能用这些数据验收的能力

- 真实课程收款、退款到账、支付宝、Apple IAP和购买授权链路：本机付款保持关闭，没有编造成功交易或财务账本。课程授权场景采用带原因和审计的后台补偿授权。
- 实物支付、发货、物流、售后；数字资料交付和预约服务履约：仅已有目录、规格、报价、购物车与未付款预览。数字/服务商品保持草稿，不能绕过服务端限制上架。
- 真实直播观看、推流、连麦与回放：仅预告和计划场次；播放器状态明确不可用。
- 活动报名、出票、签到、付费会员购买/升级以及真实版权授权：本轮数据不代表已完成这些业务。
- 本轮没有手机或原生构建验收。未实现功能仍按主任务清单记录，不因为有数据库样例就标记为完成。

## 如何补入数据和保留手动操作

在项目根目录运行：

```powershell
pnpm db:seed
```

该命令先构建现有API服务，再调用业务服务进行初始化。审核、发布、授权、作业修订、点评、通知、库存预占/释放均遵守现有业务流程。原来的少量示例脚本已改为这一套统一入口，不再生成两套互不关联的数据。

- 仅允许本机且非production的数据库；不要把开发库或测试账号用于生产。
- 第一次媒体生成使用本机Python的Pillow和imageio_ffmpeg，生成原创测试媒体，无需下载他人课件。可通过 `MANUAL_TEST_PYTHON` 指定具有这些库的Python。
- 初始化步骤记录在忽略提交的 `.runtime/manual-test-manifest.json` 中，只保存记录编号和步骤标记，不保存令牌、密码Hash或私人内容。
- 重复执行不会重复创建，也不会覆盖你后来编辑的内容、审核结果、课程授权或会员状态。**它是补入/续跑命令，不是重置按钮。**
