## 已发现并修复

1. **购课订单无法查看“全部”**：App发送空state，接口枚举校验拒绝。改为未筛选时省略state；四个筛选真实浏览器回归通过。
2. **混合课程购买说明误写为视频课**：报价及新订单快照补充发布版本的contentFormats，购买页展示“图文 · 音频 · 视频研习”；旧订单无此字段时使用原format回退。增加报价版本回归。
3. **多个阅读器互相清空选文**：阅读器全局监听在发现其他文章选区时清空整个窗口选区。清理限于自身持有的选区；选文复制/划线/笔记/评论和4项多阅读器回归通过。
4. **后台时间录入受电脑时区影响**：作业截止时间及高级维护时间字段显式按北京时间解释；活动编辑共用同一转换。跨洛杉矶、上海、东京时区验证，并实际保存09:30为01:30Z、再次编辑回显09:30。使用不携带时区偏移的DatePicker展示值，避免Ant Design标准化时转回电脑时区。
5. **笔记导出显示UTC时间**：Markdown导出时间、记录时间和文件日期统一北京时间，接口回归验证格式。
6. **测试清理外键顺序错误**：ConsumedRefresh先于AuthSession、Address先于User清理，保留数据库约束。测试运行器禁用外部开发环境的订单预占开关，并增加60秒测试超时；完整回归可正常退出并销毁临时库。
7. **浏览器种子隔离**：种子支持独立runtime/output，媒体生成支持指定输出位置，避免覆盖用户手动测试清单与媒体。

后台生产构建会更新Umi生成文件，因此构建后已重启开发后台，避免开发服务器使用过期生成文件。浏览器测试过程中的错误定位脚本/过期编译资源已修正，表中仅统计最终复测结果。
