## 隐私兼容转换及回退

先备份数据库与媒体、校验校验和，并保留**当前**DOMAIN_ENCRYPTION_KEY。不可同时更换密钥和转换字段；HMAC身份查找与AES密文都依赖当前密钥。密钥随生产私有配置保留，不写源码、审计、文档或前端包。

在API工作目录运行只读统计：

```text
node prisma/convert-private-data.mjs --mode=dry-run
```

转换必须指定实际数据库名与已核验备份引用，默认以有效admin记录操作人：

```text
node prisma/convert-private-data.mjs --mode=encrypt --confirm-database=实际数据库名 --backup-reference=已核验备份路径
```

脚本输出运行ID与数量，不输出姓名、电话、地址或密文。每批至多100条，锁记录后复核并将修改和审计同事务提交；明文/Cipher不一致则该批回滚，已完成批次可重复执行。已有规范测试账号、业务关系、交易数量及管理员密码保持。

需要旧版兼容时，在仍运行新版API的容器中，先按实际转换运行ID恢复记录，再回退镜像：

```text
node prisma/convert-private-data.mjs --mode=restore --run-id=转换运行ID --confirm-database=实际数据库名 --backup-reference=已核验备份路径
```

仅恢复该运行审计记录中的用户/地址/旧订单；已注销用户和已删除/已匿名订单跳过，不重新生成被注销的信息。恢复的是当前可授权读取的值，Cipher暂保留以支持新版兼容。新版本产生的加密记录不属于旧转换运行；如需回退到不支持Cipher的旧程序，须在维护窗口核对这些记录并采用本批兼容版本或另行恢复，不能无条件只换旧镜像。

认证临时记录只去明文，不逆向还原手机号限流键和验证码挑战；HMAC迁移保留有效验证码绑定及限流上限。回退旧身份模块前应撤销未用验证码并要求重新获取。正式短信当前关闭，因此本批线上转换不影响真实验证码接收。
