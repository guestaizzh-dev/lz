# A04/A06：付费预约与活动安排变更

2026-10-13。本轮续办49之后的付费延期、学员确认/退出、整场取消与退款恢复。完整M04、A04/A06和商用验收仍未完成；正式收费保持关闭。本轮未部署、未打包APK、未做手机验收。

## 已实现的业务规则

- 运营可延期未开始、未签到/履约的已付款咨询时段和活动场次。购买时的价格、服务内容、时间、场地和退款规则保持不可变；最新安排单独读取既有资源版本。
- 学员须确认最新安排版本，旧版本不能确认，其他账号不能代确认。未确认不能签到或履约；可退出并自动全额原路退款，即使新安排已开始，也不直接记为缺席。确认延期后可在新开始前全额退出；已签到或开始履约不能走此整单自助退款路径。
- 延期后新增购买遵循购买时的安排与取消期限，不继承其他学员的变更补偿资格或变更提醒。
- 运营取消整个时段/场次时，父资源立即停止预约、联系方式访问和核销。免费席位当场释放，付费席位保留至渠道成功退款，不能把confirmed直接清零。
- 整场取消同事务生成BOOKING_CANCEL_COMPENSATION持久任务；每批20笔，按订单项游标继续，逐订单按用户/订单/资源原锁序办理。不会在持有资源锁时反向锁用户和订单。
- 自动退款沿用Refund/Item、BOOKING_REFUND任务、支付渠道和预收冲回。已有普通待审核退约升级为取消补偿，不再允许拒绝并恢复已取消安排。已在退款中或失败的记录保留，继续通过原退款重试办理。
- 原付款、购买快照和原报名记录保留。退款成功才记录退款事实、冲回原预收并释放一次席位；成功时冻结最终安排，后续资源变动不改写已结束记录。
- 渠道异常时暂停交付并保留容量，不显示虚假的退款成功。整场取消任务耗尽重试时，在订单后台展示；有orders.read权限的授权运营/客服/财务通过渠道查询操作恢复原任务，沿原游标续办并记录操作人审计。
- 重复收款退回不影响原有效订单的自助退约入口。常规退约仍按冻结截止与财务审核办理；安排变更退款自动办理，不经过可拒绝的普通审核。
- 待支付占位、未知支付、权益预占、已签到/履约和正在退约的延期继续受保护。有占位须先查单、按原流程关闭未付款订单，再操作安排；不能绕过查单丢失库存或付款。

## App与后台

App订单展示购买时的原时间/地点、最新时间/地点、变更原因、待确认状态和取消退款进度。确认新安排使用现有弹窗，退款继续使用既有ComposeSheet；不要求填写内部ID或新的复杂表单。我的报名直接返回对应售后订单，已取消场次不再显示核销凭证按钮；订单状态明确显示退约退款中，不再误写待履约。付费咨询在我的预约保留地点/联系安排。宋体标题、清晰正文及书院既有布局保留。

官方Ant Design Pro的延期/取消组件接通已付款安排，明确区分免费立即释放和付费退款确认后释放。订单详情同时展示购买时原安排与最新/最终安排，不泄露联系方式；服务与报名工作台同步取消状态，不再向取消记录提供联系或签到动作。老师安排通知使用BOOKING_STAFF回工作台，学员退款通知返回原订单。
