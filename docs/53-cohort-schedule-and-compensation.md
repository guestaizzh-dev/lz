# 营期安排变更与本人确认退款

日期：2026-10-13。范围：A03、A04、A06 的付费营期延期、取消和开营后退出子流程。完整 M04、CO05 商用验收仍未完成。

## 已完成的子流程

| 操作 | 实际行为 |
| --- | --- |
| 未开营延期 | 整期按天顺延；固定章节开放日、作业和打卡沿原开营锚点顺延。购买时快照保留，学员确认最新安排后参与，也可全额退出。 |
| 已开营延长 | 只延长结营期限，保留开营、报名截止、章节开放和原教学日期。最新期限须本人确认，未确认时暂停学习与讨论，也可全额退出。 |
| 整期取消 | 免费报名立即释放；付费报名暂停交付，持久队列自动全额原路退款，渠道成功后一次释放席位。结束后的营期不能通过此入口改期或取消。 |
| 开营后服务核查 | 学员从原订单说明问题；财务核查实际交付、提出退款金额和依据，本人同意后才执行原路退款。拒绝恢复原期限及原安排确认状态，不追加时间。 |
| 取消时已有协商方案 | 尚未同意的方案升级全额退款并保留被替代方案摘要；已同意的金额与依据不可改写，完成原退款后补退余额，不重复释放席位。 |
| 待付订单安排变化 | 安全查单及关单后释放旧占位；未知支付结果保留库存。真实款项已到但无法交付，保留付款事实并补偿，不发旧安排报名。 |
| 学习历史 | 本人已取得的研习完成记录可以只读回看；退出后不能补发尚未完成的记录，正文和媒体权限仍关闭。独立购课及其他营期不受影响。 |

学习章节、提交作业及打卡数量只提供核查线索，不能直接按次数折算财务扣款。退款后的保留款仍留在预收账本，本轮没有把报名、签到或学习点击当收入，也没有提前生成消费积分。

## App 与后台

- App 原订单并列购买时安排和最新安排，直接确认新版安排或弹窗全额退出；开营后可申请服务核查，显示拟退款、保留款、交付依据和本人同意／拒绝按钮。
- 长退款说明采用摘要与可展开完整规则，保留原规则快照；修正部分退款已退出的状态，避免显示成仍已报名。文字操作保持轻量按钮，沿既有书院风格。
- Ant Design Pro 沿现有模板开放付费延期、已开营延长及整期取消。财务以元输入、API 以整数分处理；待本人确认时不能代其执行退款。原安排、渠道事实、退款历史及恢复任务在原抽屉显示。
- 补偿每批处理 20 条订单，保存游标、租约和重试状态；成功批次重置连续失败次数。后台查询可审计恢复耗尽重试的安排补偿任务，通知、账本和席位变化保持幂等。
- 修正支付发起与取消竞争：查单／关单遵守用户与订单锁顺序；正在发起支付时保留占位，避免先释放后出现真实付款。
