# M01 / M05 媒体交付续办

日期：2026-10-14（UTC）；按26计划继续C02/C03可独立子项及L02/L04。沿用App现有纸色、墨青布局与官方Ant Design Pro；云录制仍暂缓。本文记录本次实现与验证，不覆盖25历史商用审查。

## 已实现

### M01 课件发布与播放

- 保存音视频草稿须选对应、READY且非私人附件的媒体。提交审核与审核发布在事务中重新检查并锁定媒体，失效则整体回滚，保持原草稿/审核状态。
- 媒体库筛选与显示统一为数据库实际状态：上传中、处理中、待审核、可用、审核不通过、已删除。移除数据库不接受的FAILED状态选项。
- 私有播放凭证到期前一分钟自动续期；网络错误15秒重试，媒体出错自动尝试一次，仍失败可手动重载。续期保留位置、倍速和播放/暂停状态，不通过切章清空未同步学习事件。
- 页面隐藏、卸载、身份切换或选章使旧异步响应失效，不让旧媒体恢复播放。401/403/404/409清除媒体与字幕并显示错误；按原接口复验权限，未增加永久公开播放地址。
- 音视频章节支持SRT/WebVTT纯文本时间轴字幕；随发布版复制并冻结。公开目录只返回章节元信息；字幕正文仅在章节权限检查后返回。

### M05 人工回放与直播恢复

- 回放提交同时保存视频、实际时长、字幕和纯文本研习资料；任何修订重新进入PENDING，清除旧审核人与发布时间。普通学员不能读取待审核资料。
- Pro提交表单支持编辑旧资料、字幕及时长；审核弹窗可直接试看真实视频、检查字幕原稿与研习资料。
- 审核预览使用5分钟管理会话凭证；每次Range请求检查会话、live.review权限及回放版本。签发留审计，不借学员购课身份获取预览。
- 学员回放票据同样绑定回放版本；同一视频只改字幕/资料后重新审核，也不能让旧票据重新生效。
- 复用既有15秒恢复任务，活跃场次按最近核查时间约30秒核验一次ZEGO实际流状态；未收到开播回调仍可确认开播。发现无流先标断流，恢复后清标记；持续三分钟无流/失去主播租约后结束并撤准入。查流错误或未知业务码不自行结束；开播提醒按原幂等键不重复，恢复行为留审计。

### App 阅读与交互

同步字幕采用浅纸色文字面板，不改页面结构；播放时显示当前句，可展开全文、按时间跳转、长按选文及一键复制全文。长字幕分50段展开。回放研习资料沿正文排版，可选文复制；不会堆装饰或改整个主题。

## 数据库与接口

第43迁移：`services/api/prisma/migrations/20261014100000_media_subtitle_delivery/migration.sql`。

| 实体 | 新字段 | 约束 / 生命周期 |
| --- | --- | --- |
| CourseChapter | subtitleText text，默认空串 | 最多200000字符；录播草稿可编辑 |
| Lesson | subtitleText text，默认空串 | 发布时复制；数据库触发器禁止修改 |
| LiveReplay | subtitleText text，默认空串；notes text，默认空串 | 字幕200000、资料50000字符；随回放修订重新审核 |

服务端解析限制最多1000段、每段2000字符，校验格式、有效时间、顺序、重叠及实际时长范围；不执行字幕中的HTML。保留旧版空字幕兼容。原生界面采用text渲染，无外部字幕URL。

- 现有课程创建/修订DTO增加章节subtitleText；GET learning/lessons/:id返回授权后的subtitles数组。
- POST admin/live/sessions/:id/replay增加subtitleText、notes。
- 新增POST admin/live/sessions/:id/replay/review/preview：仅审核权限，返回管理会话绑定的短期预览。
- 现有POST live/sessions/:id/replay-ticket返回授权后的subtitles、notes；旧票据访问验证回放版本。
