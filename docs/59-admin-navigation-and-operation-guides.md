## 模块结构

| 模块 | 使用入口 |
| --- | --- |
| 工作台 | 工作台首页、数据概览、操作指南 |
| 内容运营 | 文章与经典、文章评论审核、社区与内容治理、内容联动 |
| 课程与教学 | 课程与名师、音视频媒体库、训练营管理、教学与作业、研习打卡、名师问答、课程评价审核 |
| 直播管理 | 直播间与场次、我的直播 |
| 商城运营 | 商品与库存、配送计费 |
| 会员服务 | 会员与权益 |
| 活动与预约 | 活动管理、服务与预约、现场工作台 |
| 订单与售后 | 课程订单、训练营订单、预约与活动订单、会员订单、商品订单、客服与反馈 |
| 系统管理 | 账号与会话、角色与权限、系统配置、操作审计、高级数据维护 |

菜单和工作台只展示当前账号有入口权限的业务；指南可以阅读跨岗位的整体流程，但无权限操作入口不会成为可点击链接。页面原访问 guard 和服务端权限保持生效。高级数据维护位于系统管理末尾，文案明确日常运营优先使用专用业务页面。

## 十五篇后台内置流程

1. 发布一门图文 / 音视频课程。
2. 创建直播并开播。
3. 上传、审核和发布人工回放。
4. 发布文章、经典与关联内容。
5. 开设训练营并安排教学。
6. 上架商品、发货与处理退货。
7. 发布活动、现场签到与记录履约。
8. 开放咨询服务并处理预约。
9. 配置会员套餐、权益与补偿授权。
10. 查找订单、核查收款与处理退款。
11. 创建后台账号并配置最小权限。
12. 安排老师、作业与研习打卡。
13. 答复名师问答并审核公开。
14. 审核评论、课程评价与社区举报。
15. 处理反馈、配置与排查操作问题。

其中直播流程解决此前「场次管理在哪」「怎么开播」问题：**直播管理 → 直播间与场次 → 场次管理 → 场次与回放 → 新增场次**；授权主播本人在「我的直播」准备并进入开播台，允许摄像头 / 麦克风后开始直播。结束后正式结束场次；云录制按用户要求继续暂缓，回放走人工上传与独立审核。
