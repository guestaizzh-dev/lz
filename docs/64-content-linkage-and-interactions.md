## 2. N01：混合文章发布与阅读

### 后台操作

入口：内容运营 → 文章与经典。

1. 新建草稿，正文块可选正文、经典引用、图片、音频或视频；用上移/下移调整顺序，保留段落稳定标识。
2. 音视频选择媒体库资源或直接使用同一分片上传组件。仅处理完成且类型匹配的资源可保存、送审和发布；私人附件不能挪作文章课件。
3. 保存后点击查看，使用试听音频/试看视频获取受控预览。只读审核人员也能试看，无需编辑权限。
4. 送审和发布重新校验媒体；校验失败事务回滚，不把文章误留在下一状态。
5. 发布生成ArticleRelease/ArticleBlock快照，写入媒体绑定；修订不改写旧引用和私人笔记快照。

### App交互与授权

- 文章文字、引用、图片、音视频可共存；延续现有选文/复制/笔记/评论菜单。
- 点击播放才申请5分钟凭证；不将storageKey或永久媒体地址作为正文返回。
- 播放中提前续期，恢复位置、倍速和播放/暂停状态；开始一个媒体会暂停同文其他媒体。
- 调整字号、刷新私人高亮不重建播放器。页面隐藏暂停全部媒体、停止续期，未完成的请求不会在隐藏后触发自动播放。
- 媒体失效时显示独立提示和重试按钮，文字和选文继续可用。
- 签名绑定文章版本、稳定块ID、媒体和用户会话。每次Range/HEAD/普通读取重新校验文章状态、版本、会员及会话；文章下架/修订、媒体失效、会员撤销后旧链接失效。

API：

- `POST /articles/:id/blocks/:blockId/media`
- `POST /admin/articles/:id/blocks/:blockId/media`
- 继续复用 `/media/stream` 的Range/HEAD和权限复验。

## 3. N02：来源、授权、资质与质量证据

### 运营入口

- 文章：查看文章 → 来源证据与研习引导。
- 商品：原商品详情中的来源证据入口。
- 名师：课程与教学 → 名师 → 资质与来源。
- 后台操作指南中的文章流程已补充多媒体、原件上传、核查和撤回步骤。

### 生命周期

1. 录入作者/核发单位、版本、权利人、授权范围及可公开的HTTPS来源；可以附私有PDF/PNG/JPEG/WebP原件，最大10MB。
2. 生效和截止日期按北京时间解释；拒绝不存在的日期、倒置区间及已过期的新记录。
3. 上传文件限定本人绑定，不允许把他人私人附件填成证据。不同业务分别限制可用证据类型。
4. 新记录为待核查；审核人员填写实际原因。有原件时需查看并确认核对，不能使用原来的一键固定文案通过。
5. 正文资料无覆盖编辑入口；修订通过“据此新增版本”复制资料，再填写版本/日期并重新上传，原记录保留。审核采用expectedVersion，重复并发处理只有一次成功。
6. 对已绑定的每类来源声明，送审/发布时须至少有一份当前生效的已审版本；同类型补录有效新版可恢复发布，不因保留的旧过期记录永久卡住。
7. 待审、撤回、未生效、已过期及原件失效的记录不再公开。此规则影响来源摘要及重新发布，不自动删除已发布文章、购买事实或学习记录。

### 私人原件与公开展示

- 原件使用短期、绑定后台会话/资源/证据版本的票据。每次文件读取复验绑定、会话、当前管理权限和文件状态；审核版本改变后旧链接失效。
- PDF按附件下载，带nosniff；图片供受控查看；查看原件留审计。
- 公开字段仅含来源摘要、版本、权利人、授权范围、有效期和公开来源；不返回proofAssetId、storageKey、reviewerId或内部审核原因。
- 演示档案的证据始终标识演示，不因审核操作自动升级为真实资质。
- App文章、商品、名师使用同一轻量来源展示组件，保留宋体标题、清晰正文和留白。

API复用并扩展 `admin/{articles|products|teachers}/:id/editorial`，新增 `POST evidence-files`、`POST evidence/:evidenceId/proof`，保留专用新增/审核流程。
