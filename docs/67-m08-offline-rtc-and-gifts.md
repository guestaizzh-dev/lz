## 3. 离线课件规则

- 服务端每次返回最多4MiB分片，校验当前账号会话、设备、许可证摘要、版本、文件和即时权益。客户端逐片校验，完成后再校验整份SHA-256；中断只保留已确认分片，不把Bearer令牌写磁盘。
- Android使用Keystore AES-GCM与MediaDataSource；iOS使用Keychain/CryptoKit AES-GCM与AVAssetResourceLoader。私有课件和元信息均加密，播放按需解密，不生成可随意复制的明文视频临时文件。
- 发行包固定可信公钥。`scripts/prepare-offline-trust.mjs`只导出公钥，服务端私钥不进入App。当前源码公钥映射为空，`OFFLINE_NATIVE_PLAYBACK_READY=false`，配置与验收完成前不会出现可用下载按钮。
- 许可证最长72小时，不晚于会员、限期购课或营期到期；设备重启、时钟异常需联网刷新。离线期间的撤销最迟到已签授权原到期时间生效，不能承诺完全断网时即时撤销。
- 普通购课与不同营期分别保存授权，不能互换营期刷新。签发明确确认开始交付，退款期间暂停新下载及刷新；原学习记录保留。
- App入口为课程章节“离线下载本讲”和“我的 → 离线课件”；支持暂停、继续、播放、联网刷新、删除、设备授权管理。Web只管理设备授权，不假装支持原生离线播放。

## 4. 实时互动规则

- 使用ZEGO **Express RTC** 原生桥接。Android依赖3.25.0，iOS依赖3.24.0；不是旧版nvue直播插件或ZIM即时通讯插件。永久AppSign及服务端密钥不进入App。
- App入口：“我的 → 我的直播”和“我的 → 在线咨询”。Web端明确引导使用App进行采集；原有后台电脑开播台继续可用。
- 咨询必须为已确认的`IN_APP_RTC`预约，接受最新安排；只允许预约学员和负责老师，于开始前5分钟至结束后5分钟进入。退款、取消、账号或老师权限失效会停止续期，持久巡检负责服务商踢出恢复。
- 连麦同时只邀请/连接一位学员。会员优先只依据购买时冻结的三级会员版本`micPriority`，不自动替旧会员添加权益；优先仍需主持审批及本人确认设备采集。
- 主播移出学员不关闭主播自己的麦克风；学员结束连麦后重新建立观看连接。场次结束、离开和服务商终态会释放连麦记录与租约。
- 观看不申请麦克风/摄像头；本人明确确认采集后才申请系统权限。切换到音频开播后，凭证刷新不会把摄像头重新打开。

## 5. 礼物资金与后台流程

### App

“我的 → 礼物余额”提供充值包、余额明细、订单与退款。直播“心意”区逐次明示花费与金额，赠送后只做轻淡入提示，保持原米白墨青和宋体标题。

100书香点=人民币1元，与免费积分独立，不设过期。未实际确认收款不会产生可消费来源；余额不允许为负。赠礼按购买来源分摊，重复请求不会多扣，源单、场次、礼物版本和合同费率可追溯。申请退款先冻结原购买来源；驳回恢复原来源，渠道确认退款后才记退款完成。

Android使用已有微信/支付宝App支付渠道；iOS仅Apple消耗型产品，不引导外部购买。StoreKit 2适配只用于本次礼物购买，运行于iOS15以上；App整体最低版本仍保留原设置，低版本明确提示。服务端确认已交付/已撤销后才`finish`；取消、待处理、断网或待财务核查不结束交易，可恢复未完成交易。此项不代表课程/会员C08已经验收。

Apple强制撤销已消费金额时，追回未消费余额，已经消费的坏账按当前合同由平台承担，暂停账户赠礼待核查；原老师分成不被静默改写。退款撤回使用反向分录恢复原来源。部分金额或重复撤销周期不猜金额，保留核查。

注销前必须处理剩余付费礼物余额及渠道核查，不能因用户注销直接没收余额。

### 后台

**财务中心 → 直播礼物与分成**有四个工作区：

1. 礼物与充值：充值包版本、礼物目录、Apple不可变产品映射和启停。
2. 老师与合同：真实合作方登记、私有合同原件、分成及有效期；新合同版本默认暂停，核对后单独启用，历史赠礼不改写。
3. 充值与退款：原单金额、渠道、未消费来源、退款审核/驳回、先核对渠道再重试；原请求被渠道明确关闭后才轮换退款编号，保留审计。
4. 老师分成结算：已结束的北京时间自然月，只纳入未结算来源；生成、另一位财务复核、实际银行付款后登记交易号/时间/私有凭证。**记录实际付款不等于系统自动银行转账。**

已加入操作指南、菜单权限、统一财务业务筛选及持久任务恢复。免费积分、余额流水和分成事实均不能通过通用CRUD伪造；合同及付款原件使用会话绑定短凭证，撤销财务权限后不可继续查看。

默认`GIFT_SALES_ENABLED=false`、`APPLE_GIFT_SALES_ENABLED=false`；没有真实合同与正式渠道时不收款。`RTC_NATIVE_PUBLISH_READY`和`OFFLINE_NATIVE_PLAYBACK_READY`也默认关闭，布尔配置及Apple依赖关系在启动时校验。
