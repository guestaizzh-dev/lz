## 2. 操作入口

- Pro「营销运营 → 营销中心」：优惠券与课程拼团，支持指定课程选择、起止时间（北京）、限领和暂停。
- Pro「内容运营 → 社区活动与授权」：置顶申请、征文活动、投稿评选、课程案例审核。
- Pro「课程与教学 → 课程案例点评」：只处理本人主讲课程、作者明确授权的心得；与审核发布分开。
- Pro「会员与权益 → 权益版本 → 调整新售社区权益」：每自然月申请次数与最长置顶天数；旧版本不变。
- Pro「配送计费」：真实覆盖说明、合同有效期和私有证明；商品订单包裹可查物流。
- 操作指南：`/guide?workflow=marketing`、`community-enhancements`、`logistics`。
- App「我的 → 优惠券」：领券、本人券、输入拼团邀请编号；购课确认页选择单买/拼团、展示原价/优惠/实付。
- App「我的 → 书院共创」：征文、本人投稿、置顶申请与案例授权结果；帖子可申请置顶；笔记/日志可选定心得授权课程案例。
- App「隐私说明」：个性化推荐开关；商品订单可查看物流及原优先服务约定。

## 3. 业务与数据约束

1. 不新建平行收款、库存或积分账本。课程营销沿用TradeOrder/Item、PaymentTransaction、Refund、FinanceJournal及持久OutboxJob。
2. 优惠券条款领取时冻结；停止领取不改变旧券，过期返还不续期。一单一券、拼团不叠券，支付金额至少1分。
3. 拼团未成时收款记预收，成团后逐原始付款转课程收入；失败按预收原路退回，重试不重复授权/转收入/退款。客户只能在团成后学习。
4. 新增ForumPinApplication与CourseCase，两者均有真实来源、本人归属、版本与审计；既有WritingCampaign/CampaignEntry/ContentAuthorization/GrowthLedger继续复用。
5. 课程案例仅保存本人编辑授权的文本加密副本；后台无默认访问私人原件的入口。删除原记录同步清理该副本并撤回，注销清除授权和案例；物流缓存同样随注销清理。
6. 优先配送在DeliveryZone上扩展，普通及会员免基础费不免优先附加费；历史订单原服务、实付金额和运费分摊不重算。
7. 新的营销及配送配置移出通用写数据编辑器，必须通过专用工作流；权限沿用课程运营/社区审核/本人教学/商品与订单能力。

## 5. 正式资源与恢复条件

- R01/R02：需正式微信/支付宝真实收退款、异常回调及双端发行证据；iOS不开放外部营销价。
- R07：服务器设置`LOGISTICS_TRACKING_ENABLED=true`及真实`KUAIDI100_CUSTOMER`/`KUAIDI100_KEY`，并核验隐私告知与实际运单；优先服务必须使用真实覆盖/合同材料。无配置不伪造轨迹、覆盖或时效。

- R04/R08/R09/R13：仍需正式运营内容、当前源码双端发行和实际使用验收。新会员配额只影响新售版本。
