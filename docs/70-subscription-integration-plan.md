# R15 自动续费与升降级：接入核对与恢复计划

日期：2026-10-16。状态：**未完成，渠道前置依赖未就绪**。不是自动续费交付报告，不提高商用完成度。

## 1. 当前实际能力

现有会员是固定期手动购买：Android经微信/支付宝可信收款后发放，iOS服务端仅识别非续期订阅。跨层级按已确认的原期限排队，不能用修改会员到期时间、后台开关或重复加30天冒充订阅。

仍缺内部自动续费状态机、原生订阅购买/管理、可信渠道账期与宽限、价格变化和升降级联动。不能表述为“只差填配置”。M09其余14项内部实现也不代表已取得正式渠道验收。
