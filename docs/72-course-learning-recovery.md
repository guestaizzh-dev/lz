## 2. 定位到的具体问题

1. **初次媒体失败无法完整重试**：学习页原先在拿到媒体票据前就写入`lesson/selectedId`。票据失败后，重试只刷新目录/进度，不再请求该章节媒体，可能出现视频不显示或音频按钮无效。
2. **直播章节依赖失败留下半成品状态**：章节详情成功但场次查询失败时，选中章节和实际交付状态不一致。
3. **迟到失败可覆盖后续页面状态**：原章节选择的成功分支有页面/身份检查，但异常分支未做同等检查；目录刷新也缺独立请求代次。离开/重新进入/会话变化时旧结果可能回写。
4. **课程详情刷新失败仍显示旧操作**：原错误组件只在`!course`时显示。已有课程对象后，权益刷新失败会继续显示旧目录和购买/继续学习入口。
5. **混合课连续学习入口不明显**：切换下一讲必须回到目录，本轮用现有按钮补前后章入口，不自动跳过锁定章节，不自动播放。
