# A05 付费预约、活动与营期实际履约及收入确认

日期：北京时间2026-10-18。补齐付费服务的内部交付与财务处理子流程；正式渠道、真实服务材料、现场/双端及完整商用验收仍未完成。会员M08消费奖励尚未由本功能发放。

## 1. 后台操作

沿用「预约与活动订单」「训练营订单 → 查看与处理」，增加「实际履约与收入确认」，不新增另一套订单或空白数据编辑页。

1. 服务或营期结束后，运营登记实际结果、交付数量、给学员的说明和内部依据，并上传本人的私有PDF/图片凭证。咨询按约定分钟，活动按参加人数，营期按固定版本必修章节（无必修时为全部章节）。活动交付人数不能超过有效签到；部分交付可以覆盖全部参加人数，具体不足在凭证和说明中记录。
2. 填写**本单累计确认收入**，默认完整交付按剩余实付预填；不是每次重复增加金额。超过剩余实付、未结束、安排未确认、正在售后及无有效收款均不放行。部分/未到场按真实情况起填，不能通过签到或付款自动完成。
3. 另一位具备财务权限的人员在本记录「查看原始凭证」后，勾选核对并说明复核依据。服务端同时验证本人查看凭证的审计事实；提交人即使是ADMIN也不能自审。通过后实际交付结果生效，按确认金额记预收转收入；驳回不动原账务，运营可重新提交。
4. 更正另建下一版，保留原始记录/凭证/会计分录，只记累计收入差额。原订单收款/退款、报名或安排变化使待审快照失效，必须驳回重核，不能用旧凭证确认新事实。同一订单只允许一份待复核；请求重试不会重复建单、记收入或退款。

## 2. 退款与状态

- **未交付**：财务核实后，收入累计目标为0；如有剩余实付，自动走原支付渠道退回。渠道成功前保留席位，暂停继续交付；确认成功后原流程释放一次。已部分退出的原席位不再次释放，仅补退剩余资金。
- **部分交付**：只按实际确认金额入收入，剩余资金保持预收；学员仍可在原订单申请服务核查与协商退款。财务提出金额/依据，继续由本人确认后退款，没有替用户同意。
- **未到场**：记录事实，默认不自动扣费或记收入，保留预收待真实服务条款/售后核查。仍可申请服务核查，拒绝方案恢复原NO_SHOW状态。不得虚构已完成服务来处理未到场费用；明确费用约定及实际运营仍属正式验收内容。
- **已确认收入后的退款**：先减少尚未确认收入的预收，再冲回必要的收入，不把预收科目记成负数，不重写历史分录。异常或重复收款仍按原异常待退科目处理，不变成收入。
- **已退出记录补录/更正**：保留退出/退款和库存事实，只能依真实历史安排与有效凭证核算；不恢复原服务资格，不重新扣款。已有最终安排快照沿用，不因后来改期重写历史。

预约订单重复的查单入口已合并：只有主按钮用于继续付款时才保留单独查单，完成/售后状态从底部主按钮统一查询，不误显示刷新报价。App原预约/营期订单显示已审核的结果、实际数量、学员说明、核查时间与版本。内部依据、原文件、人员审计和收入核算字段不发给学员；部分交付/未到场不再笼统显示「履约已完成」，未交付显示真实退款进度。原已购课程、其他报名和会员权益不改写。
