# 81 App 界面一致性与控件修复

日期：2026-10-19。范围：App 现有 74 个路由的共享视觉层，以及用户截图点名的商品详情、文章评论/来源、商城、购物车、首页、会员、搜索、社区、设置。不改变七板块导航、后端业务、支付开关与商用状态。

## 1. 根因

| 现象 | 根因 |
| --- | --- |
| 来源区、消费奖励像没排版，出现白底方块按钮 | 样式隔离 2.0 下，`SourceEvidence`、`ConsumptionReward` 使用了 `.text-button/.meta/.item-title` 等全局类，却没有引入 `styles/app.css`，退回浏览器/平台默认样式 |
| 数量加减、购物车出现白色圆角块，图标被盖住 | 平台给 `disabled` 的 `button` 追加浅灰背景与透明度；盖在图标上的透明点击层、加减按钮被画成白块 |
| 商品“加入购物车/确认规格与配送”一个像描边一个像纯文字 | 禁用态依赖平台默认外观；主按钮和次按钮的禁用表现不一致 |
| 商城“推荐”和“新品”同时高亮 | “推荐”绑定分类、“新品”绑定排序，默认状态同时命中 |
| 卡片价格上下错位 | 标题/说明行数不同，价格行没有固定基线 |
| 评论时间比作者高、删除/回复不齐、引用断成两行 | 作者与时间行高不同、操作按钮 padding 不同、引用标签与正文分成两个块 |
| 文章正文与评论之间大段空白 | 阅读器 `static/reader` 底部留白 64px，叠加评论区 26px |
| 会员套餐选中卡偏蓝、说明字号过大 | 选中态使用 `#EFF2EF` 冷色底，说明沿用 16/29 正文 |
| 首页名师名 9px、直播预告挤在半栏、出现孤立“›” | 双栏布局与过小字号；名师“更多”只写了一个箭头 |
| 商品/课程确认页显示英文 `property … should not exist`、课程页渲染崩溃 | 线上 API 仍是较早镜像，App 发送了新字段；课程页直接读取旧接口没有返回的 `groupOptions.length` |

## 2. 本批修改

- `styles/app.css` 建立单一基线：纸色/纸面/淡洗/细线、页边 16、区块 24、行高 48、标题 22/18/16、正文 15/27、按钮 46 高 23 圆角；新增 `.is-disabled` 显式禁用态，替代平台默认外观。
- 来源与消费奖励组件引入全局样式并按新层级重排；来源复制改为描边胶囊，不再出现白底方按钮。
- 商品数量改为 44px 图标按钮组；购物车数量同形，并把“□/☑”字符换成真实复选框。
- 商品、购物车、商城团购/会员等主按钮改为显式禁用类 + 点击守卫，禁用时仍是可辨认的按钮。
- 商城筛选只保留“最新/热销/价格”；商品卡固定标题两行、说明两行，价格行对齐。
- 评论区统一作者/时间 22px 行高、操作行 40px、引用单行、回复缩进线；阅读器底部留白 64→24。
- 首页名师与直播改为全宽两段，去掉孤立箭头，老师名 9→11px；直播链接取消 12px 左缩进。
- 搜索、社区、研习方向统一描边胶囊选中态；会员套餐选中卡改为纸面 + 墨青描边，说明降为 13/22。
- 报价请求只在必要时发送新字段（商品 `PRIORITY`、课程 `ALIPAY_APP`），兼容当前旧 API；课程页对缺失的 `groupOptions` 做空值处理；class-validator 英文错误统一转中文；课程原价缺失时回退实付价。
