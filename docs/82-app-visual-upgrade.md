# 82 App 视觉升级：直播与课程售卖

日期：2026-10-19。范围：App 全部现有页面的共享视觉层，重点重做书院直播（列表/详情/观看）与课程售卖（详情/播放/购课/订单/学习档案）。不改变后台、导航七板块、业务规则与支付开关。

## 1. 设计基线 v2

- 纸色 `#F5F0E6`、纸面 `#FCF9F2`、淡洗 `#EFE9DC`、墨 `#182B31`、次墨 `#344C54`、灰 `#6A7578`、墨青 `#235663`、金 `#A67C46`、陶红 `#B4533F`、细线 `#E3DCCF`。
- 页面标题 26/36，详情标题 24/35，区块 19/29，条目 16.5/25，正文 15/27，眉题 10/16 字距 2。
- 纸面卡 12 圆角 + 1px 暖线；主按钮 48 高 24 圆角；状态胶囊；金色只用于眉题、直播、师承与礼遇。
- 新增通用件：`.eyebrow/.pill/.card/.card-ink/.media/.display/.thumb-row` 与 `.pill-text`。
- 全局色值一次扫齐 `pages/`、`components/`、`App.uvue`、`marketing.css`、`reader.css`、`pages.json` tabBar 与导航底色。

## 2. 直播

- 列表：深色墨青大图 hero + “LIVE · 书院共研”眉题 + 预告胶囊；三格价值说明；近期直播卡改为横图 + 状态胶囊 + 标题/摘要 + 箭头。
- 详情：墨青大图 hero（分类/权限、标题、摘要、主讲），场次卡带状态胶囊、北京时间、整宽预约/进入直播按钮；新增“观看提示”卡（提醒、共研、回放与记录）。
- 观看：视频区统一 12 圆角墨色舞台，直播中/回放改为带圆点胶囊，重连按钮与状态同一行。
- 直播互动组件沿用全局纸面/胶囊体系；礼物、投票、共研、延伸研习统一标题层级。

## 3. 课程售卖

- 课程详情：封面改为可点播的 12 圆角媒体，左上课程类型/示例胶囊，中央播放圆钮；标题区改为眉题 + 24 号标题 + 副题 + 元信息；价格卡与老师卡独立纸面卡；研习方向改为胶囊标签。
- 课程学习：修复 `LessonRow` 未引入 `app.css` 导致 `.row` 失效、标题/试听/元信息竖排错位的问题；改为序号圆、标题 + 试听胶囊、格式图标 + 元信息、右侧状态圆（完成/锁定/播放）。
- 学习档案：顶部统计改为墨青卡 + 米金数字；课程卡统一纸面、进度条、下一讲与继续学习按钮。
- 购课确认：标题/课程摘要卡、课程与交付/直播安排/购买方式/费用明细/退课说明全部改为纸面卡；应付金额与支付渠道、勾选与底部合计固定；关闭平台默认禁用白底。
- 购课订单：订单改为纸面卡（日期 + 状态胶囊、课程行、金额与入口），空态与“去学堂选课”保留。
- 课程播放：课程标题/试听目录/filters/讲次/正文/目录/上一讲下一讲沿用新的字号与纸面卡；目录与课件条目更紧凑。

## 4. 全页面

- 首页：四个区块增加“书院选读/研习路径/书院师承/LIVE”眉题；精选经典、直播预告、课程行、名师行统一纸面卡和 12 圆角。
- 学堂/发现：列表前加“课程目录/文章目录”眉题；课程行摘要两行、标签胶囊、价格 17；文章行标题 16.5、摘要 13、元信息 11。
- 名师/活动：名师卡改为头像 + 姓名/头衔 + 简介 + 领域胶囊；活动卡改为大图 + 线下活动胶囊 + 日期 + 标题 + 地点/价格。
- 搜索：结果增加 64×64 封面缩略图；筛选胶囊、选中态、结果间距统一。

- 我的：菜单拆为“研习与书院 / 订单与服务”两组并加金色组眉题；会员条、设置、行高统一。
