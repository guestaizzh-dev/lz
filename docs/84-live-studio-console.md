# 直播开播台改版（2026-10-19）

## 1. 问题

旧开播台是「后台表格 + 一个白底弹窗里塞 iframe」：1000×600 的弹窗、摄像头画面按 4:3 原样缩在中间，两侧大片黑边；麦克风、摄像头、开始/结束按钮散落在 iframe 自己的小工具条里，被弹窗挡住；没有状态、没有计时、没有检查项。现场看起来像调试页面，不像直播产品。

## 2. 改版内容

**后台开播台（全屏演播室）**

- 顶部：书院印章标识、场次主题、状态徽章（准备中/直播中）、直播计时、全屏与关闭。
- 主区：16:9 画面舞台，深色底、圆角、内外描边；左上角「预览 · 未推流 / 正在向学员直播」，右下角水印。
- 控制条：麦克风、摄像头、填充/适应切换、状态提示、开始直播 / 结束本场。按钮与状态实时同步。
- 右侧栏：场次信息、开播检查（摄像头/麦克风/推流/网络）、学员入口说明、三条提醒。
- 离开保护：直播中关闭会二次确认；Esc 关闭；结束本场需填原因，结束后立即关闭观看。

**播放器页（iframe 内）**

- 深色画布，画面默认 `cover` 填充，可切换 `contain`；嵌入模式隐藏自带工具条，只保留画面，控制全部交给开播台。
- 进入开播台即创建本地预览流（静音播放避免自动播放拦截），点「开始直播」才推流；推流成功后才向学员可见。
- 与父页面用 `postMessage` 同步：`start / mic / camera / fit / fill` 下行，`studio-state` 上行（仅同源）。

## 3. 验证

- `client.js` 通过 `node --check`；后台 `tsc --noEmit` 与生产构建通过。
- 设计稿渲染截图（1600×900 与 1366×768）：`outputs/live-studio-preview.png`、`live-studio-live.png`、`live-studio-1366.png`，源文件 `outputs/live-studio-preview.html`。
- 发布 `20261019-live-studio-01`：线上后台入口引用新包 `umi.269b3622.js`，`/api/v1/live/player/client.css` 含嵌入规则、`client.js` 含 `studio-state`，健康检查 200。

未验证：真实摄像头下的画面比例与声音（本机无摄像头）、多显示器全屏、Safari 兼容。

## 4. 边界

- 没有设备选择器（多摄像头切换）、没有观众数、没有弹幕上屏、没有云录制——这些属于后续增强，不在本次范围。
- 推流鉴权仍为关闭状态（`ZEGO_ROOM_TOKEN_AUTH_ENABLED=false`），正式上线前需要开启。
