# 直播统一运营与自动回放

日期：2026-10-20。最新方案为管理员统一运营及ZEGO官方服务端本地录制，替换55/57中的多角色流转与人工回放主流程。

## 业务目标

管理员发布主题、北京时间和内容 → 同一后台检查设备并开播 → 全部有效会员在App观看 → 结束后处理并发布回放。预约仅作提醒；不分配老师、不进行跨角色审核、不展示礼物。

- [x] 更新操作指南、需求/技术决定与计划执行记录。

## 录制决策

用户明确指出采用ZEGO官方服务端本地录制，已按此纠正：Linux C++ SDK 6.39.0.51681，服务器直接登录RTC房间，仅录主讲流，私有媒体卷保存；不使用浏览器录制，不依赖对象存储。官方SDK和示例已实际下载校验，原生程序在目标Linux编译通过，并通过独立真实RTC房间生成17.162秒H.264/AAC录像，两个音视频轨道起始时间与时长相同。云录制不是当前方案。

## 兼容与验收

新会员直播不要求选择老师；历史绑定课程/老师的直播、已购固定版本及退款限制保留，不批量改写旧权限。重复发布/开播/结束/上传不得重复生成直播或回放。回放需保留会员鉴权和断点拖动能力，不能暴露永久公开地址。

界面沿用官方Ant Design Pro与现有App风格。主操作明确，投票/连麦等放次级工具，不堆在主列表。商用完成度须有实际证据才更新。

- `services/api/src/live-broadcasts.ts`：一站预告、编辑、取消、开播与回放操作；管理员身份、幂等及版本冲突处理。
- `services/api/src/live-recordings.ts`、`services/recorder/recorder.cpp`：持久录制任务、SDK子进程/Token续期、低磁盘保护、恢复与回放处理。
- `apps/admin/src/pages/live-discovery/Broadcasts.tsx`：单入口、状态筛选、预告表单、录制失败重试及回放预览；沿用官方Pro。
- `apps/admin/src/pages/live-host/Studio.tsx`：设备预览、录制就绪门禁、中断提示、重试、结束及误关闭保护。
- `apps/mobile/pages/live/`、`components/LivePlayer.uvue`：真实状态、北京时间、会员入口、结束页、回放与Web播放状态/画面适配。

- `apps/admin/src/operations/`：菜单合并及新的开播/回放指南；历史课程直播保留独立兼容入口。
