## 参考与取舍

实际查看了[抖音直播](https://live.douyin.com/)及文化分类、[快手直播](https://live.kuaishou.com/)及公开直播间，也查看了 [ZEGO 官方开源直播示例](https://github.com/ZEGOCLOUD/zego_uikit_prebuilt_live_streaming_example_flutter)。参考画面优先、轻量输入、分层工具和主播预览的组织方式；没有将 Flutter/UIKit 依赖引入 uni-app x，也没有加入礼物、榜单或虚构人气。

书院列表/详情继续使用现有纸色主题；观看与开播使用深色舞台、低对比边界和少量金色操作。标题保留文化气息，实时评论和控制使用清晰的正文字体。

## 调整位置与理由

| 位置 | 已完成调整 | 原因 |
| --- | --- | --- |
| `apps/mobile/pages/live/index.uvue` | 用实际直播/待开播/回放内容作为头图，显示真实状态和北京时间；增加刷新安排；列表标注进入/回放/详情 | 原来的固定口号与装饰入口占用首屏，不能直接回答当前有什么可看 |
| `apps/mobile/pages/live/detail.uvue` | 去掉重复简介、重复提醒和编号装饰；保留主题、正文、时间及实际观看/预约按钮 | 降低重复信息，纠正未开播时“提前进入”的误导 |
| `apps/mobile/pages/live/watch.uvue` | 默认完整画面，可切换铺满；清屏隐藏顶栏、评论和操作栏并提供恢复入口；连接/等待/直播/结束区分；连麦退出确认；返回键优先关面板；隔离旧请求 | 课件不能被默认裁切，清屏应真正安静，网络状态不能伪装成直播中 |
| `apps/mobile/components/LiveDiscussion.uvue` | 底部短输入，最近四条评论；历史独立入口；消息连接失败可重试；长按复制/写感悟/举报；待审说明和字号、时间、分隔线整理 | 点普通评论不再误开大面板，复制和完整阅读都有明确入口 |
| `apps/mobile/components/ComposeSheet.uvue` | 为直播增加可选紧凑深色样式，正文输入与发送状态保留；原页面继续使用原样式 | 复用已有草稿、键盘避让和失败处理，不再另造一套编辑器 |
| `apps/mobile/components/LiveRoomSheet.uvue` | 深色历史消息面板、安全区、关闭按钮、Web 宽度限制 | 弹层与直播画面协调，避免桌面过宽 |
| `apps/mobile/components/NativeRtc.uvue` | 连麦面板增加遮罩，点击外侧可关闭 | 防止操作设备时误触后面的直播内容；不自动申请采集权限 |
| `apps/mobile/components/LivePlayer.uvue` | iframe 加载后获取当前状态，切换完整/铺满保持原连接 | 避免错过早期状态消息，不为改显示模式重复入房 |
| `apps/admin/src/pages/live-host/Studio.tsx` | 设备/录制就绪提示，开播等待与防重复，原画预览，真实开播时间计时，控制按钮状态及官方图标 | 管理员清楚知道当前是预览还是已推流，也知道为何暂时不能开播 |
| `apps/admin/src/pages/live-host/StudioTools.tsx` | 发言一键审核通过并记录原因；拒绝/移除仍填写原因；待审数量；看旧消息时提供回到最新入口 | 减少常用审核步骤，保留审计，阅读历史时不强制跳动 |
| `apps/admin/src/pages/live-host/studio.css` | 减少渐变/大阴影，统一圆角和状态色，深色表单聚焦，窄屏布局，消息管理操作按需显现 | 控制区与互动栏协调，画面成为主体 |
| `apps/admin/src/pages/live-discovery/Broadcasts.tsx` | 开播台接收最近轮询到的场次信息 | 恢复连接或服务端确认开播后，时间与版本保持更新 |
| `services/api/public/live/client.js`、`client.css` | SDK 确认后才显示播放中；开播重复保护与 20 秒超时恢复；嵌入播放器去掉重复等待文案；声音按钮避开聊天区 | 修正状态误报、重复推流和叠层冲突，不改变服务端准入与录制权限 |
