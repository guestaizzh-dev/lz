# 会员中心与会员订单的状态反馈（2026-10-25 第 4 轮）

本轮把上一轮购课订单的做法延伸到会员：检查会员中心、会员购买与会员订单在加载、刷新、超时和分页失败时的反馈。未改会员价格、权益、退订规则与支付渠道。

## 本轮评估的不足

1. 会员中心每次进入都先把已确认的会员状态和权益清空再请求：有效会员会短暂看到“暂未开通会员”，权益区消失又出现。
2. 首次进入时 `loading` 为 false，套餐列表为空，会先闪一下“此层级套餐尚未发布”。
3. 刷新时整页出现“正在整理内容”，已加载的套餐被挡住；底栏按钮只是看起来禁用，实际仍可点击进入购买页。
4. “查看更多用量”失败会把页面级错误打开（整块“暂时无法打开”），已加载的用量与翻页位置丢失，重试只能整页重载。
5. 会员订单列表把套餐名显示两次（标题与副标题重复），没有显示实际生效日期；超时未付的会员订单仍写“待支付”和“查看与支付”。

## 改动

| 位置 | 改动 |
| --- | --- |
| `apps/mobile/pages/membership/index.uvue` | 只在账号变化时清空会员与权益；首次进入即为加载态；刷新时保留已加载套餐，仅在没有套餐时显示整页加载；分页用量失败改为局部提示并可原地重试；底栏按钮在加载/错误/未选套餐时不再响应 |
| `apps/mobile/lib/membership-sales.ts` | `membershipOrderLabel` 对 `paymentStatus=EXPIRED` 的待支付订单显示“支付已超时” |
| `apps/mobile/pages/membership/orders.uvue` | 副标题由套餐名改为实际生效日期（无会员记录时显示套餐天数）；超时订单入口改为“查看订单” |
| `apps/mobile/pages/membership/purchase.uvue` | 超时未付订单的说明改为“付款期限已结束，本次订单不会扣款；如需开通请重新选择套餐” |
| `services/api/test/course-purchase-ui.test.mjs` | 新增会员订单与期限标签断言（超时/待确认/部分退款/全额退款/退款办理中） |

## 验证

- 购课与会员标签单元测试 5/5 通过。
- HBuilderX 5.26 Web 导出与 Android 蒸汽模式字节码编译均 76 页面、0 编译错误（既有 `<button>` 子元素、`aria-hidden` 警告不变）。
- 会员相关页面需要登录态与套餐数据，本轮未做数据态截图；改动集中在条件渲染与文案，构建通过，接口契约未变。

## 仍未处理

- 列表页（课程订单、会员订单、学习档案、直播列表）的 `load()` 以 `loading` 作互斥，直接改初始值为 true 会挡掉首次请求而停在加载态；需要增加“已发起过一次”的标记再统一首帧状态，本轮已尝试并回退，留到下一轮集中处理。
- 会员中心套餐选择仍是可点击 `view`，Web 键盘用户无法选择套餐，需要与全站可访问性一起改。
- 退款准入规则三处不一致、直播租约清扫重试上限，见 [91](91-code-and-interaction-review-2026-10-25.md)；原生 `<button>` 子元素疑点见 [93](93-live-room-performance-and-payment-feedback.md)。
