# 直播房间准入去重与订单分页错误（2026-10-25 第 6 轮）

本轮处理一处直播轮询的性能热点，以及预约/训练营订单追加加载的局部错误反馈。未改准入规则、订单状态与接口字段。

## 本轮评估的不足

1. 直播详情每 15 秒轮询一次，房间内每个场次都完整执行一次准入判断（公开资源、课程上下文、会员、退款、课节绑定）。同一个房间的场次共享同一份准入规则快照，除“按课节绑定”外结果完全相同，会员直播/公开直播因此重复几十次相同查询。
2. 预约订单与训练营订单的“加载更多”失败仍把整页变成“暂时无法打开”，已加载记录消失，重试只能从第一页重来。

## 改动

| 位置 | 改动 |
| --- | --- |
| `services/api/src/live.ts` `room()` | 按场次准入规则快照分组：非“按课节绑定”的场次每组只执行一次准入并把结果复用到同组场次；只有课节绑定的场次逐场判断（它必须核对本场是否属于所购版本）。同一请求内用 Promise 缓存避免并发重复。 |
| `apps/mobile/pages/booking/orders.uvue`、`pages/cohort/orders.uvue` | 追加加载失败改为列表下方局部提示，保留已加载订单；按钮变为“重新加载”，失败时回退页码 |

效果：会员直播、公开直播、未绑定课节的课程直播从“每场次一次准入”降为“每个规则一次”；课节绑定的课程直播保持原有逐场校验（规则正确性优先）。

## 验证

- API 构建通过；直播相关测试 41/41 通过（含课程准入、会员权益、回放凭证、取消、心跳、录制恢复）；另跑直播投票、房间控制、观看生命周期与学习 27/27 通过。
- HBuilderX 5.26 Web 导出与 Android 蒸汽模式字节码编译均覆盖 76 页面、0 编译错误（既有 `<button>` 子元素、`aria-hidden` 警告不变）。
- 未做请求次数与耗时的自动化断言：现有测试关注行为而非查询条数；同组复用不改变返回结构，由 41 项直播测试覆盖语义。
- 数据态截图仍缺（需登录与真实直播数据）。
