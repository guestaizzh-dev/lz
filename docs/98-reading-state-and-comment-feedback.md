# 阅读页状态保持与评论反馈（2026-10-25 第 8 轮）

本轮检查文章阅读与评论链路，修正返回页面时的状态闪烁、字号无反馈以及评论列表的错误处理。未改接口、阅读器协议或内容权限。

## 本轮评估的不足

1. 从评论编辑器或其他页面回到文章时，`loadPrivate()` 先把点赞、收藏与全部标注清空再请求：心形/星标会短暂熄灭，已划线内容消失一下。
2. 底部“字号”只切换 14/16/18/20，没有显示当前字号，用户只能从正文变化猜。
3. 评论列表首帧 `loading=false`，会先闪“暂无评论”；“查看更多回复”失败会把整段评论换成页面级错误，重试还会重置已加载分页。
4. 评论组件有未使用的 `total` 计算、`blocks` 属性与 `.section-count` 样式。

## 改动

| 位置 | 改动 |
| --- | --- |
| `apps/mobile/pages/article/detail.uvue` | 仅在账号变化时清空点赞/收藏/标注，同一账号返回页面保留现有状态并静默刷新；底部字号显示当前值（如“字号 16”） |
| `apps/mobile/pages/article/comments.uvue` | 增加 `ready`，完成首次请求后才显示空状态；展开回复失败改为提示，不再整页报错；错误重试保留失败的追加分页；删除未使用的计算、属性与样式 |

## 验证

- HBuilderX 5.26 Web 导出与 Android 蒸汽模式字节码编译均覆盖 76 页面、0 编译错误（既有 `<button>` 子元素、`aria-hidden` 警告不变）。
- 本轮未改 API 与服务端契约，未重跑 API 测试。
- 本地库没有已发布文章与评论，阅读页数据态无法在本机截图；改动以条件渲染与行为路径为主，构建通过。
- 兼容性：`Comments` 组件仅被文章页使用且只传 `resourceId`，删除未使用的 `blocks` 属性不影响调用方。

## 仍未处理

- 阅读页底部工具栏、评论“回复/查看更多”等可点击 `view` 在 Web 仍不可键盘操作。
- 阅读器内选中/标注的原生交互仍需真机复核（本轮未触及阅读器引擎）。
- 购课/播放/直播的数据态截图需要本地种子内容或获授权的只读环境。
