项目：老子道学书院；产品形态：Android / iOS App + Web 运营后台。

1. 先读 [产品需求与实施契约](01-product-requirements.md)：这是业务范围、已选定规则、订单/权益状态、原文覆盖和验收的基线。
2. 再读 [技术调研与选型](02-technical-research-and-decisions.md)：这是 uni-app x 蒸汽模式、后端、数据库、支付、音视频、构建和环境的执行决策。
3. 首个实现任务执行技术文档 S01/S04/S05/S07，按真实工具与沙箱结果记录版本及能力，之后按需求第 13 节拆解功能。
4. 最新界面指令：App设计已由用户提供，执行[用户设计图实施说明](06-app-reference-implementation.md)；后台直接二次开发Ant Design Pro模板。后台来源、启动和部署说明见[模板二次开发记录](../apps/admin/THIRD_PARTY.md)。旧App设计稿不是已接受的实施基线。

用户已授权开发代理自行决定模糊业务事项；不得反复为普通实现选择寻求确认。用户明确的新指令始终高于这套文档。

R1 是七板块的基础正式版；R2 补齐增强功能；R1 完成不能被描述为原始策划全部完成。AI/虚拟名师/线上道场仅为 R3 展望。
