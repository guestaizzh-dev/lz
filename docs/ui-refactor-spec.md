# App 视觉重构规格（所有页面统一执行）

目标：360–430dp 宽度下，每页都符合下面的值与规则。只改样式与页面内文案/间距结构，**不改业务逻辑**（API 调用、权限判断、金额计算、路由、缓存）。

## 1. 颜色（只允许这些）

| 用途 | 值 |
| --- | --- |
| 页面纸色 | `#F5F0E6` |
| 纸面（卡片/输入） | `#FCF9F2` |
| 淡洗（分组底） | `#F0EADD` |
| 线（卡边/分割） | `#CFC5B1` |
| 弱线（列表行） | `#E0D8C8` |
| 墨（标题） | `#182B31` |
| 次墨（正文） | `#344C54` |
| 辅助（说明） | `#5C6869` |
| 极弱（脚注） | `#7A847F` |
| 青（主操作/选中） | `#235663` |
| 淡青（选中底） | `#E6EDE9` |
| 金（眉题） | `#8A6635` |
| 淡金（礼遇） | `#F1E8D8` |
| 陶红（仅价格/警示） | `#B4533F` |
| 禁用底/字 | `#E4DED2` / `#6F6A5F` |

禁止：纯白 `#fff`/`#FFFFFF` 作按钮底、纯黑 `#000`、以及上面没列出的灰/青/金色值。

## 2. 字号与行高（一一对应，禁止碎值）

| 字号 | 行高 | 用途 |
| --- | --- | --- |
| 26 | 36 | 首页品牌/大标题 |
| 24 | 34 | 详情页主标题 |
| 19 | 28 | 区块标题 |
| 17 | 26 | 卡片标题/状态标题 |
| 16 | 24 | 条目标题 |
| 15 | 26 | 正文 |
| 14 | 24 | 次要正文 |
| 13 | 22 | 说明、条款 |
| 12 | 20 | 元信息 |
| 11 | 17 | 眉题（仅金色或辅助色） |

禁止 10、10.5、12.5、13.5、15.5、16.5、18、20、22 等值。已有 18/20 的改成 19/17。

## 3. 圆角与间距

- 圆角：卡片 14、媒体 10、主/次按钮 23–24、胶囊 10、输入 10。
- 间距只用 4 / 8 / 12 / 16 / 24 / 32。
- 页面左右内边距 16；区块之间 32；卡片内边距 16；列表行上下 14–16。
- 首屏第一个区块距页头 16；页尾至少 40 内边距。

## 4. 组件规则

- **页头**：详情页一律用 `PageHead`；列表页用页内标题（24/34 + 13/22 说明），标题与第一块间距 16。
- **列表行**：上 15 下 15、底部 1px `#E0D8C8`；缩略图 96×72 或 88×88、圆角 10；标题 16/24 最多两行；元信息 12/20 `#5C6869`。
- **卡片**：`#FCF9F2` 底 + 1px `#CFC5B1` + 圆角 14 + 内边距 16。
- **按钮**：主 48 高 / 23–24 圆角 / `#235663` 实心白字 / 15px；次 46 高描边 `#C9BFAD`、字 `#235663`；文字操作 13px `#235663`，左右留白 8、热区 ≥44。
- **胶囊**：11/17、内边距 3×9、圆角 10；只用 pill-live / pill-gold / pill-teal / pill-muted 四种。
- **页签**：46–48 高；选中 = 600 字重 + 2px 青色下划线 + `#182B31` 字；未选中 `#5C6869`；不要容器整行描边（否则出现双线）。
- **输入**：高 44–48、`#FCF9F2` 底、1px `#CFC5B1`、圆角 10、字号 15。
- **开关**：关闭态轨道 `#D8D1C2`，开启 `#235663`，行尾配 12px 状态文字。
- **空/错/无权限态**：必须走 `ContentState`；`error` 时按语义传 `errorTitle`（如「无权查看」「内容不存在」「网页端不支持」），`retryable=false` 时不显示重试而显示 `actionLabel` 的出口按钮。禁止"暂时无法加载 + 重试"套在所有失败上。
- **底部操作条**：`BottomBar` + 主操作；条上边 1px `#E0D8C8`；内容区末尾留 24 以上，避免正文贴条。

## 5. 硬性检查（每页都要过一遍）

1. 无 10px 文字；11px 仅眉题且用金/辅助色。
2. 12px 以上文字对比 ≥4.5:1（上面颜色表已满足，别自定义浅色）。
3. 可点区域 ≥44×44；纯文字链接加点按内边距。
4. 无纯白按钮、无 `opacity` 低于 0.5 的可读文字（禁用态用色值，不用透明度）。
5. 长标题最多两行；`max-height` 用行高整数倍（24×2=48）。
6. 首屏不得出现空白过大的段落（>320px 空洞需补信息或收紧间距）。
7. 文案不得出现「测试 / 示例 / 样例 / 演示 / 占位 / 尚未接入」，也不得编造资质、价格、收款事实；不确定的事实性表述改成"以订单/页面为准"。

## 6. 禁止使用的 CSS（原生不支持）

`gap`、`display:grid`、`vh`/`vw`、`calc()`、`max()`/`min()`、`position:sticky`、`backdrop-filter`、伪元素 `::before/::after`、`:hover`、`transform`、`aspect-ratio`、`line-clamp`、`text-wrap`、`env()`、`box-shadow` 大范围阴影。

只用 flex + 固定 px 值；横排用 `flex-direction:row`，等分用 `flex:1`。

## 7. 允许改动的范围

- 该页 `<style>` 块内的值、类名、少量新增页面类。
- 模板里的类名、文案、间距容器；不得新增页面或改动 `pages.json` 路由。
- 不得修改 `styles/app.css`、`styles/controls.css` 与共享组件（如需共享改动，写进汇报由主代理统一处理）。
