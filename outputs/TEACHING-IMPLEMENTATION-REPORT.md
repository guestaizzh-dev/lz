## 🔧 技术实现细节

### 幂等性设计

**作业提交**:
```typescript
operation = 'assignment.submit:' + assignmentId
payloadHash = sha256(JSON.stringify(dto))
cache = IdempotencyRecord.findFirst({ userId, operation, requestKey })

if (cache) {
  if (cache.payloadHash !== payloadHash) 
    throw ConflictException('提交标识已用于其他内容')
  return cache.response // 返回缓存结果
}

// 首次提交：创建 + 存储幂等记录
```

**点评并发**:
```typescript
// FOR SHARE 锁住作业和用户
await tx.$queryRaw`SELECT id FROM "Assignment" WHERE id=${id} FOR SHARE`
await tx.$queryRaw`SELECT id FROM "User" WHERE id=${userId} FOR UPDATE`

// 乐观锁版本号
changed = await tx.submission.updateMany({
  where: { id, state: 'SUBMITTED', version: expectedVersion },
  data: { state: outcome, version: { increment: 1 } }
})
if (!changed.count) throw ConflictException('此提交已处理')
```

### 附件凭证设计

**生成凭证**:
```typescript
payload = {
  submissionId, assetId, userId, sessionId, 
  sessionKind: 'APP' | 'ADMIN',
  expires: Date.now() + 5 * 60000
}
encoded = base64url(JSON.stringify(payload))
signature = hmac-sha256(encoded, secret)
ticket = encoded + '.' + signature
```

**验证流程**:
```typescript
1. 验签（HMAC-SHA256）
2. 检查过期时间
3. 验证会话有效性（kind + sessionId）
4. 验证提交归属（学员本人 或 课程老师）
5. 验证附件绑定（AttachmentBinding表）
6. 流式返回媒体
```
